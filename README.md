# Proyecto TFG
Memoria dedicada a los contenidos del Proyecto Intermodular de la fp superior de Administración de Sistemas y Redes (ASIR).

## Sprint 0

Hasta el momento, lo que he hecho hasta ahora ha sido empezar a plantear el desarrollo del concepto de la carpeta en la nube/red social de desarrollo GitHub donde van a ir siendo modificados tanto publicados todos los archivos en los que se van a 
componer el proyecto. Después lo que he hecho es un clon de dicho repositorio en modo texto desde el terminal del cmd 
del entorno de desarrollo de Visual Studio Code para por lo que pueda pasar, por eliminación accidental, tener una copia
de seguridad de todos los archivos en un espacio seguro en el que no puedan caer en malas manos y en el que queden seguros. 
Después en Visual Studio Code he sincronizado mi repositorio de GitHub con el entorno, y ahora puedo acceder de forma instantanea a los archivos y hacer todas las modificaciones que quiera en ellos.
