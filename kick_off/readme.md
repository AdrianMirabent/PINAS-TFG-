# Kick off

Se comienza  a plantear el desarrollo del concepto en el entorno colaborativo, creando el repositorio en GitHub donde van a ir, siendo modificados tanto publicados todos los archivos en los que se van a componer el proyecto tanto teóricos tanto prácticos. 

Después lo que he hecho es un clon de dicho repositorio en local desde el terminal del IDE Visual Studio Code para por lo que pueda pasar, por eliminación accidental, tener una copia de seguridad de todos los archivos en un espacio seguro en el que no puedan caer en malas manos y en el que queden seguros y para trabajar más cómodamente. Después en Visual Studio Code he sincronizado mi repositorio de GitHub con el entorno, y ahora puedo acceder de forma instantanea a los archivos y hacer todas las modificaciones que quiera en ellos.

Seguidamente hemos creado nuestro tablero Kanban en Trello donde vamos a hacer un seguimiento de tareas por hacer, haciendo y completadas. 

Por último le hemos dado forma a la idea y hemos redactado el anteproyecto de nuestro TFC que ya ha sido aprobado por el profesor.
